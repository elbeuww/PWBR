## Spacing Scale

Échelle 8-point standard (multiples de 4). Identique à l'existant vitrine (`px-4`/`md:px-6`, `py-16`, `mt-4`, `space-y-8`, `gap-2`).

| Token | Value | Usage Académie |
|-------|-------|----------------|
| xs | 4px | Gaps d'icône (callout icône↔texte), padding badge |
| sm | 8px | Gap entre badges thème/niveau/plateforme (`gap-2`), espacement compact |
| md | 16px | Padding horizontal page (`px-4`), gap interne carte, padding callout |
| lg | 24px | Padding de section, gap grille de cartes (`gap-6`), padding carte (`p-6`) |
| xl | 32px | Espacement entre sections de contenu (`space-y-8`) |
| 2xl | 48px | Séparation index ↔ grille, marge sommaire ↔ corps |
| 3xl | 64px | Padding vertical de page (`py-16`) |

Exceptions :
- Largeur de lecture prose : `max-w-prose` (~65ch) pour article/leçon (aligné `methodologie/page.tsx`).
- Largeur index/grille : `max-w-6xl` centré (liste articles+cours).
- Cibles tactiles nav préc./suiv. leçon : min 44px de hauteur (≥ `h-11`) — confort mobile, seule dérogation hauteur.

## Typography

Hérité Phase 2. **3 tailles principales + 1 display**, **2 graisses** (regular 400 + semibold 600). Aucune autre graisse. Interlignage corps 1.5 (latin) / 1.6 (arabe via `:lang(ar)`), titres ~1.2.

| Role | Size | Weight | Line Height | Classe Tailwind |
|------|------|--------|-------------|-----------------|
| Display (titre article/cours, H1) | 28px | 600 | 1.2 | `text-2xl font-semibold` |
| Heading (H2 sections, titres de carte, titre leçon) | 20px | 600 | 1.3 | `text-xl font-semibold` |
| Body (corps prose, résumés) | 16px | 400 | 1.5 | `text-base` |
| Label (badges, méta temps de lecture, légendes captures, TOC, bandeau fallback) | 14px | 400/600 | 1.4 | `text-sm` (semibold sur libellés actifs) |

Règles :
- H3 dans le corps MDX = `text-base font-semibold` (pas de 5e taille) — réutilise le pattern `methodologie`.
- Aucune graisse `font-bold` (700), `font-light`, `font-medium` sauf le `font-medium` déjà porté par `badge.tsx` (hérité, ne pas modifier).
- `font-heading` apparaît dans `methodologie/page.tsx` mais N'EST PAS défini dans `@theme` (no-op silencieux) → **ne pas l'utiliser** ; utiliser `font-semibold` directement.

## Color

Hérité Phase 2 — palette bleue institutionnelle, 2 thèmes (light/dark via next-themes `.dark`). **Vert/rouge INTERDITS** (D-04 : réservés au trading, aucun widget trading dans l'Académie). `destructive` = gris neutre, jamais rouge.

| Role | Value (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `--background` #FFFFFF / #0B1220 | Fond de page, surface de lecture prose |
| Secondary (30%) | `--card`/`--secondary` #F4F6F9 / #141C2B | Cartes index, header, footer, encadrés callout, encadré « exemple de trade », sommaire |
| Accent (10%) | `--primary` #1E5FBF / #3B82F6 | Voir liste réservée ci-dessous |
| Destructive | `--destructive` #5B6675 / #9AA7B8 (gris neutre) | Non utilisé en lecture (aucune action destructive dans cette phase) |
| Texte atténué | `--muted-foreground` #5B6675 / #9AA7B8 | Méta (temps de lecture), résumés, légendes, body de section |
| Bordures | `--border` #E2E7EE / #26303F | Séparateurs sections, contour cartes, bordure encadrés |

**Accent (`--primary`) réservé STRICTEMENT à :**
- Liens contextuels actifs (TOC item courant, lien « voir le cours », lien funnel home « Apprenez les bases »).
- Boutons de navigation leçon préc./suiv. (état par défaut = `variant="outline"`, hover/focus en accent ; le CTA primaire d'un parcours peut être `variant="default"` plein primary).
- Barre `Progress` de progression d'un cours.
- Focus ring (`--ring` = primary, hérité).
- Badge de filtre **actif/sélectionné** sur l'index (variant `default` = bg-primary).

**Accent JAMAIS utilisé pour :** badges thème/niveau/plateforme au repos (→ `variant="outline"` ou `secondary`), icônes de callout, fond de carte, texte de corps.

Callouts pédago (D-09) — **pas de couleur sémantique vert/rouge** :
- ⚠ Attention : encadré `bg-card border-s-4 border-primary` (filet logique `border-s`, RTL-safe) + icône lucide `AlertTriangle` en `text-foreground`. Pas d'ambre/rouge.
- 💡 Astuce : encadré `bg-card border-s-4 border-border` + icône lucide `Lightbulb` en `text-muted-foreground`.
- Distinction = icône + libellé i18n, jamais la seule couleur (a11y, et cohérence D-04).

## Layout & Interaction Contracts (surfaces de lecture)

> Prescriptif pour le planner/executor. Toutes les surfaces sont RSC trilingues, RTL-safe (propriétés logiques `ms-*/me-*`, `ps-*/pe-*`, `text-start`, `border-s-*`), montées sous `[locale]/(marketing)/academie`. `setRequestLocale(locale)` + `getTranslations('academy')` en tête. `params` `await`és (Next 15).

**1. Index `/[locale]/academie`**
- Conteneur `max-w-6xl mx-auto px-4 py-16 md:px-6 text-start`.
- En-tête : H1 `text-2xl font-semibold` + sous-titre `text-base text-muted-foreground`.
- Barre de filtres (thème / niveau / plateforme) : composants `Select` shadcn ou groupes de `Badge` cliquables ; état actif = `Badge variant="default"`, repos = `variant="outline"`. Mécanique filtres via `searchParams` RSC (à confirmer en planif — searchParams vs client, précédent FilterBar signaux D-03-01-D : parse par enum, valeur hors-enum ignorée).
- Grille responsive : `grid gap-6 sm:grid-cols-2 lg:grid-cols-3`.
  - **Carte article** (`Card`) : image de couverture (ratio 16:9, `next/image`), titre `text-xl font-semibold`, résumé 2 lignes `text-sm text-muted-foreground`, rangée de badges (thème/niveau/plateforme) `gap-2`, méta temps de lecture `text-sm text-muted-foreground`.
  - **Carte-parcours cours** (`Card`) : idem + indicateur « parcours » (badge `outline` « Cours ») + nombre de leçons. Visuellement distincte de la carte article (badge type + libellé CTA « Commencer le cours »).
- Empty state (0 résultat après filtre) : bloc centré, heading + body + bouton « Réinitialiser les filtres ».

**2. Article `/[locale]/academie/[slug]`**
- Largeur lecture `max-w-prose mx-auto px-4 py-16 md:px-6 text-start`.
- En-tête : image de couverture pleine largeur, H1, rangée méta (badges + temps de lecture).
- **Sommaire (TOC)** ancré pour contenus longs : liste de liens d'ancrage `text-sm`, item courant en `text-primary`. Position : en flux mobile, latéral `sticky` desktop (≥ `lg`) côté `end` logique.
- Corps MDX : prose, H2 `text-xl font-semibold`, H3 `text-base font-semibold`, body `text-base` interligne 1.5.
- Composants MDX maison (D-09) : callouts (⚠/💡), étapes numérotées (`<ol>` stylé, compteur en `bg-secondary`), captures légendées (`figure` + `figcaption` `text-sm text-muted-foreground`), encadré « exemple de trade ».
- **Encadré « exemple de trade »** : `Card bg-card border border-border p-6`, libellés `text-sm text-muted-foreground`, valeurs prix/SL/TP/R:R **enveloppées dans `<bdi>`** (anti-inversion RTL, précédent D-02-03-A / dashboard affilié). Aucune couleur vert/rouge.
- Pied : `border-t border-border pt-6` + `<Disclaimer />` (auto-injecté).

**3. Cours `/[locale]/academie/[slug]` (parcours)**
- En-tête cours (titre + résumé + image), puis **liste ordonnée des leçons** (`ol`), chaque item = lien vers la leçon avec son ordre et son titre.
- `Progress` shadcn = progression dans le parcours (accent primary).

**4. Leçon `/[locale]/academie/[cours]/[lecon]`**
- Même gabarit lecture que l'article (prose `max-w-prose`, composants MDX, `<Disclaimer />` en pied).
- Indicateur « Leçon {current} sur {total} » `text-sm text-muted-foreground`.
- **Navigation préc./suiv.** en pied : 2 `Button variant="outline"` ancrés `start`/`end` logiques (RTL : « précédent » suit la direction de lecture), libellés i18n, hauteur ≥ `h-11` (cible tactile). Désactivé/masqué aux bornes (première/dernière leçon).

**5. Bandeau fallback traduction (D-14)**
- Surface UI à part entière. Quand `(slug, locale)` manque mais existe en FR : rendre la version FR + bandeau `Alert` (shadcn, `variant` neutre — jamais destructive/rouge) en tête de contenu, copy `academy.fallbackBanner`, icône `Languages`/`Info` lucide. **Ne jamais 404** un contenu existant dans une autre langue.

**6. Liens funnel (D-08)** — surfaces hôtes existantes, ajout de liens i18n :
- Home marketing (`[locale]/(marketing)/page.tsx`) : bloc « Apprenez les bases » → `/[locale]/academie`.
- Espace membre signaux (`[locale]/(member)/signaux`) : lien contextuel « Comment exécuter ce signal ? » → cours plateforme.
- Header principal (`[locale]/layout.tsx`) : entrée permanente « Académie » dans la nav (i18n, `lint:i18n` exit 0 — pas de chaîne en dur, cf. nom de marque exclu via `// i18n-ignore`).
