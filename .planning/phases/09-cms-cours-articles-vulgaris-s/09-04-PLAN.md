| URL `(slug, locale)` → route RSC | segments d'URL publics → résolution fichier (validée dans content.ts, Plan 02) |
| URL searchParams → index | filtres publics → parseAcademyParams (Plan 01) |
| Frontmatter compilé → page | frontmatter de compileMDX re-validé Zod à la page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-PATH | Tampering / Info Disclosure | routes détail → content.ts | mitigate | Résolution (slug,locale) déléguée à `resolveContent` (Plan 02) qui valide slug/locale et confine le chemin sous content/academie/ AVANT fs. La route ne concatène jamais de chemin brut. |
| T-09-02 | Tampering | routes détail (frontmatter) | mitigate | `FrontmatterSchema.parse` du frontmatter compilé ; échec → notFound/erreur, jamais 500. |
| T-09-LEGAL | Repudiation (légal) | injection Disclaimer | mitigate | `<Disclaimer />` rendu par la page après `{content}` (RESEARCH Pattern 2) → non-contournable même si un MDX l'omet. Vérifié E2E en preview (Plan 05). |
| T-09-XSS | Tampering | compileMDX | accept | Allowlist fixe `MDX_COMPONENTS`, aucun raw-HTML passthrough, aucune compilation de MDX fourni par l'utilisateur (contenu repo, RESEARCH §Security). |
| T-09-SEO | Info Disclosure (SEO) | sitemap hreflang | mitigate | `alternates.languages` n'annonce que les locales réellement présentes ; le fallback FR sous /ar n'est PAS déclaré hreflang=ar (Q3). |
