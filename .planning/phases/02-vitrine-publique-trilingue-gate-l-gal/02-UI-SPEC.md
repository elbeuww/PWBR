# Phase 2 — UI Design Contract

> Visual and interaction contract for the public trilingual showcase (home, pricing, signup→"paiement bientôt", legal pages, global disclaimer footer, dark/light toggle, self-hosted Arabic font). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Brand law (D-01):** serious, credible institutional finance. Sober, trust-inspiring, anti-scam. NOT crypto-neon, NOT flashy, no gradients-for-the-sake-of-it, no neon glow.
> **RTL is first-class:** every component uses CSS logical properties (`ms`/`me`/`ps`/`pe`/`start`/`end`), never `left`/`right`. Both themes validated in `dir=rtl` (ar).
> **Semantic-color law (D-04):** green/red are RESERVED for trading semantics (long/short, results). In Phase 2 there are NO trading widgets, therefore green/red MUST NOT appear at all (no decorative success/error greens/reds beyond the single neutral-styled form-error treatment defined below).

## Spacing Scale

Declared values (multiples of 4 only). Tailwind v4 default 4px scale is kept; below is the token usage contract.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, inline chip padding |
| sm | 8px | Compact stacks, badge padding |
| md | 16px | Default element spacing, card inner padding, paragraph rhythm |
| lg | 24px | Card padding, gap between cards, form field spacing |
| xl | 32px | Sub-section internal spacing |
| 2xl | 48px | Gap between home sections on mobile |
| 3xl | 64px | Gap between home sections on desktop, page top/bottom padding |

Exceptions:
- **Touch targets:** all interactive controls (theme toggle, language switcher, CTA buttons, nav links) MUST be ≥ 44px in the tappable dimension (icon-only buttons = 44×44). Visual size may be smaller; padding makes up the target.
- **Content max-width:** prose/legal pages capped at `max-w-prose` (~65ch); home content container `max-w-screen-xl` centered with `px-4 md:px-6 lg:px-8` (logical: `ps/pe`).

## Typography

Two weights only: Regular 400 + Semibold 600. Body line-height 1.5; heading line-height 1.2. Arabic gets +0.1 line-height per role (diacritics) via `:lang(ar)`.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 (UI labels, badges, footer disclaimer text, form labels) |
| Heading | 24px | 600 | 1.25 (section titles "Comment ça marche", pricing card titles, legal H2) |
| Display | 40px (mobile) / 56px (≥md) | 600 | 1.15 (hero H1 only) |

Notes:
- Exactly 4 sizes, 2 weights — within contract.
- Hero subtitle/lede uses Body 16px (or 18px optional, still 400) — do NOT introduce a 5th weight.
- Numbers (prices) wrapped in `<bdi>` and rendered with `Intl.NumberFormat`; tabular figures if available.

## Color

Institutional blue brand. 60/30/10 split. Tokens are CSS variables; values below are the contract for BOTH themes (light value / dark value).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Light `#FFFFFF` / Dark `#0B1220` (near-black navy) | Page background, primary surfaces |
| Secondary (30%) | Light `#F4F6F9` (cool grey) / Dark `#141C2B` (slate navy) | Header, footer, cards, pricing card surface, nav |
| Accent (10%) | `#1E5FBF` (brand blue; Dark `#3B82F6` for contrast) | Primary CTA buttons, active link/state, focus ring, key headline emphasis, pricing "recommended" badge |
| Destructive | NOT USED in Phase 2 | — (no destructive actions this phase) |

Text/border supporting tokens (not part of the 60/30/10 accent budget):
- Text primary: Light `#0B1220` / Dark `#E6EBF2`. Text muted: Light `#5B6675` / Dark `#9AA7B8`.
- Border: Light `#E2E7EE` / Dark `#26303F`.
- Form-error treatment (signup validation): **neutral, NOT red** — error text uses Text primary at weight 600 + a muted border emphasis + lucide `AlertCircle` icon in `currentColor`. This honors D-04 (red reserved for trading). Acceptable alternative: a desaturated amber `#B45309` strictly for form-level validation, never green/red.

**Accent reserved for (explicit, never "all interactive elements"):**
1. Primary CTA buttons ("S'abonner / Voir les tarifs", "S'abonner" on pricing cards).
2. Active/current nav link and active language/theme state.
3. Keyboard focus ring (`:focus-visible`) across all interactive elements.
4. The single "recommended/découverte" pricing badge.
5. One emphasized word/segment in the hero H1 (optional).

Everything else (secondary buttons, links at rest, borders, icons) uses neutral text/border tokens. **No green, no red anywhere in Phase 2.** Contrast: all text/background pairs meet WCAG AA (4.5:1 body, 3:1 large) in BOTH themes.
