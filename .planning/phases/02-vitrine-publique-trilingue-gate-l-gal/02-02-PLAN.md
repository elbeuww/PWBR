## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL segment `[doc]` (légal) → résolution serveur | Paramètre dynamique contrôlé par l'utilisateur ; doit être borné par une allowlist avant rendu. |
| URL segment `[locale]` → résolution serveur | Layout modifié (greffe Footer) — ne pas régresser hasLocale/notFound (T-01-05 P1). |
| Variable d'environnement `LEGAL_REVIEW_DONE` → code serveur | État runtime lu uniquement côté serveur (`server-only`) ; ne doit jamais fuiter au client ni être bypassable. |
| Contenu légal i18n → markup | Texte = clés de messages, jamais d'injection HTML brute. |
