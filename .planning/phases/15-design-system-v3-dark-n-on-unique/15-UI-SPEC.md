# Phase 15 — UI Design Contract

> Visual and interaction contract for the **dark néon unique** design system. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Scope: promote the landing `.nxl[data-theme="green"]` semantic layer into a single frozen global dark theme. GREEN is the locked product decision (THEME-03 tranché). No light theme, no toggle, `forcedTheme="dark"`.

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (already initialized) |
| Preset | `radix-nova` — `components.json` present (`apps/web/components.json`), `baseColor: neutral`, `cssVariables: true`, `prefix: ""` |
| Component library | Radix UI (`radix-ui` package) via shadcn `ui/` (20 components already in `apps/web/src/components/ui`) |
| Icon library | lucide-react |
| Font | Display: Archivo 800 · Body/UI: Space Grotesk · Mono/numeric: JetBrains Mono · Accent: Chakra Petch · Arabic: Noto Sans Arabic (all self-hosted via `next/font/local`, `lib/fonts.ts`) |
| Styling | Tailwind v4 CSS-first (no `tailwind.config`), 3-layer token system in `src/styles/globals.css` (primitive → semantic → component) |
| Theme strategy | `next-themes` class strategy, migrating to `forcedTheme="dark"`; `.dark` selector retained (CandleChart + sonner observe it) but `:root` carries the frozen GREEN values so it cannot flip |

**Migration rule (THEME-01, Pitfall #1 — no mechanical de-scoping):** Promote `.nxl[data-theme="green"]` values into the **semantic layer** (`:root` in `globals.css`), do NOT copy-paste `.nxl` selectors globally (overflow). Primitive layer (`@theme --nexa-*`) and component layer (`@theme inline` shadcn names) stay intact. Only the semantic layer (Layer 2) flips — and it stops flipping once frozen.

## Spacing Scale

Declared values (multiples of 4). The landing `.nxl` uses ad-hoc px (28/26/64…); the **platform** standard is the 8-point scale already established in v2.0/Phase 11. This phase does not introduce new spacing — it inherits the platform scale.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, badge padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, header height block |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Radius tokens (existing, kept): `--radius: 0.625rem` (10px) → `radius-sm` 6px, `radius-md` 8px, `radius-lg` 10px, `radius-xl` 14px.

Exceptions:
- Touch targets: interactive icon controls (ThemeToggle removed; LanguageSwitcher kept) must stay ≥ 44px (`min-h-11 min-w-11`) — a11y, RTL-safe.
- Landing `.nxl` keeps its own internal spacing (it is a self-contained scoped surface); this phase does not retrofit `.nxl` paddings.

## Typography

Single frozen dark theme. 4 sizes / 2 weights for the platform UI (shadcn surfaces). Display uses Archivo 800 (locked).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label / meta | 14px | 600 (semibold) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px+ (clamp on landing up to 76px) | 800 (Archivo, `--display-weight: 800`) | 1.0–1.2 |

Rules:
- Body family = Space Grotesk via `--font-sans` (resolved in `@theme inline`), fallback `system-ui`.
- Numeric / tabular trading values = JetBrains Mono (`--font-mono`).
- Arabic (`:lang(ar)`) = Noto Sans Arabic, `line-height: 1.6` (diacritics) — already in `globals.css`, must be preserved (THEME-04).
- Display uppercase + tracking from `.nxl` is landing-scoped; platform headings stay sentence-case unless a reskinned surface opts into the display treatment in Phase 16.

## Color

**Single theme = GREEN, frozen in `:root`** (THEME-03, locked by user). Values promoted verbatim from `.nxl[data-theme="green"]`. Verified contrast: primary/bg **11.39:1**, text/bg **18.93:1**, muted/bg **6.76:1** — all WCAG AA+ (THEME-05).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#070b08` (bg) / `#0b110d` (bg2) | Page background, app shell, marquee/band backgrounds |
| Secondary (30%) | `#0f1611` (surface-solid) + `rgba(255,255,255,0.035)` (translucent surface) | Cards, popovers, nav bar, sidebar, dialogs, table rows |
| Accent (10%) | `oklch(0.84 0.18 150)` cyber green (primary) | See reserved-for list below |
| Destructive | `oklch(0.68 0.2 24)` / `--nexa-signal-bear` | Destructive actions only (delete, cancel-subscription confirmations) |

Supporting tokens (frozen `:root`):

| Token | Value | Role |
|-------|-------|------|
| `--foreground` / text | `#eafff1` | Primary text on dark |
| `--muted-foreground` / sub | `rgba(212,244,224,0.64)` | Secondary text |
| muted/disabled | `rgba(212,244,224,0.40)` | Tertiary / placeholder |
| `--border` / line | `rgba(255,255,255,0.10)` | Borders, dividers |
| line-soft | `rgba(255,255,255,0.06)` | Subtle section separators |
| `--primary-foreground` / on-primary | `#051009` | Text/icon ON the green primary (dark ink, high contrast) |
| glow | `oklch(0.84 0.18 150 / 0.55)` | Box-shadow glow on primary surfaces ONLY (buttons, active pills, popular price card) |
| signal-bull (trading) | `oklch(0.82 0.18 150)` (buy) | Trading direction — bull (distinct from brand per D-05) |
| signal-bear (trading) | `oklch(0.68 0.2 24)` (sell) | Trading direction — bear |
| risk/warn | `oklch(0.82 0.15 80)` amber | Moderate-risk ScoreRing only |

**Accent reserved for (explicit — never "all interactive elements"):**
- Primary CTA buttons (`btn-primary` / `Button variant=default` → `bg-primary text-primary-foreground`)
- Focus rings (`--ring` = primary green; replaces the legacy hardcoded `ring-[#2563EB]`)
- Active state of segmented controls (LanguageSwitcher active item)
- Eyebrow text + dot, section eyebrows
- Links/accents inside headings (`.accent`), checkmarks in pricing lists
- "Popular" price card border + glow, price badges
- Hero aura / globe / data-rain ambiance (color-mix derived, opacity-capped)

**Color guardrails (THEME-02 scan targets — must be eliminated or tokenized in this phase):**
- Hardcoded focus ring `ring-[#2563EB]` (institutional blue, v2.0 residue) in `ThemeToggle.tsx` + `LanguageSwitcher.tsx` (lines 168, 200) → must become `ring-ring` / `ring-primary`. **Tailwind utility collision flag.**
- Raw palette utilities `text-amber-700 dark:text-amber-400`, `text-emerald-700 dark:text-emerald-400`, `bg-red-500/10`, `border-emerald-600/30` etc. in `(admin)/sante`, `(admin)/signaux`, `(admin)/file`, `(admin)/affiliation/*`, `affiliation/dashboard`, `track-record/TrackRecordView` → must route through semantic tokens (`text-destructive`, `text-[--signal-bullish]`, `bg-muted`…). These are the "CSS bespoke par page" the scan must prove absent.
- `ring`/glow collision: glow is a `box-shadow`, never a Tailwind `ring-*` utility — keep them distinct so `focus-visible:ring-*` does not double-render against the brand glow.

**Translucent-surface AA (THEME-05):** Cards/overlays/glow cards use `rgba(...,0.035)` / `color-mix` surfaces. Contrast must be measured against the **composited** background (#070b08 base), not the translucent layer alone — overlays, glow cards, and backdrop-blur nav must each pass AA for their text. A contrast test fixture must cover the composited cases, not only solid `:root` pairs.

## Copywriting Contract

This phase is infrastructure (token migration + theme freeze). It ships **no new product screens**, but the theme-removal touches existing chrome. Copy below covers the surfaces this phase mutates and the states a checker validates. All strings stay trilingual (fr/en/ar, strict key parity — `theme-parity.test.ts`). FR is canonical.

| Element | Copy |
|---------|------|
| Primary CTA | (inherited, unchanged) FR « Commencer » / EN "Get started" / AR «ابدأ» — primary button now renders via `--primary` GREEN, label not introduced here |
| Empty state heading | N/A for this phase (no data surfaces introduced) — inherited surfaces keep their existing empty states |
| Empty state body | N/A — do not invent; existing member/admin empty states unchanged |
| Error state | Theme cannot fail at runtime (frozen `:root`, no fetch). If `next-themes` script is blocked: page still renders dark because `:root` carries the frozen values (no light fallback exists) — this is the no-FOUC guarantee, not an error path |
| Destructive confirmation | Inherited destructive flows (e.g. cancel subscription) keep existing copy; only their color routes to `--destructive`. Do not add new destructive actions in this phase |

**Removed UI (locked):** The `theme` i18n namespace (`toggleLabel`, `light`, `dark`) becomes dead once `ThemeToggle` is deleted. Keep keys in messages OR remove from all three locales together to preserve strict parity — do not remove from one locale only (breaks `theme-parity.test.ts`). Recommended: remove the `theme` namespace from fr/en/ar in the same change.

## Interaction & Theme Contract (phase-specific)

| Concern | Contract |
|---------|----------|
| Theme provider | `<ThemeProvider attribute="class" forcedTheme="dark">` — drop `defaultTheme="light"` and `enableSystem`. `forcedTheme` makes `next-themes` always write `.dark` and ignore stored/system prefs (THEME-01/04). |
| `<html>` class | `.dark` always present (forced). `:root` AND `.dark` resolve to the same frozen GREEN values, so no path exposes light. Keep `suppressHydrationWarning`. |
| No-FOUC | `:root` carries the frozen dark values → first paint is dark even before the `next-themes` script runs. No light flash possible (THEME-01). |
| Toggle removal | Delete `ThemeToggle.tsx`, its import + render in `[locale]/layout.tsx` (lines 22, 82), and the floating `.nxl-theme-toggle` path. No code path may call `setTheme('light')`. |
| sonner | `ui/sonner.tsx` reads `useTheme()` → under forcedTheme resolves to `dark`; toaster stays dark-consistent. |
| CandleChart | `CandleChart.tsx` observes the `.dark` class mutation to re-read tokens (line 167). Forced `.dark` is stable → chart reads GREEN tokens once, no flip. Recolor via lwc JS API, never bespoke CSS (Pitfall). |
| RTL (THEME-04) | Single `<html lang dir>` in `[locale]/layout.tsx` preserved. Logical properties only (`ms-*`, `inset-inline-*`); no physical `ml/mr/left/right`. `[dir="rtl"] .nxl` mirrors globe/marquee. Arabic `:lang(ar)` font + line-height 1.6 untouched. |
| Reduced motion | All landing animations already double-guarded under `prefers-reduced-motion: no-preference`. Freeze must not remove these guards. |
