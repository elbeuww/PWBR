# Phase 3 — UI Design Contract

> Visual and interaction contract for the gated member signals surface: signal list (sortable/filterable card grid, realtime), and trade detail (candlestick chart with entry/SL/TP + simple-then-deep explanation). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Inherits the Phase 2 brand contract in full** (`02-UI-SPEC.md` + live tokens in `apps/web/src/styles/globals.css`). This spec ADDS only what the signals surface needs: trading-semantic green/red, the NEUTRAL score color, signal component anatomy, data-state copy, and the additive glossary mechanic. Where P2 already fixed a value (spacing scale, type scale, brand tokens, fonts, icon lib), it is reused verbatim, not re-decided.
>
> **Brand law (D-01 P2):** serious, credible institutional finance. Sober, anti-scam. No neon, no gradients-for-the-sake-of-it. Target = non-technical MENA audience → vulgarization first.
> **RTL is first-class:** every component uses CSS logical properties (`ms`/`me`/`ps`/`pe`/`start`/`end`), never `left`/`right`. The chart canvas stays LTR; numeric values wrapped in `<bdi>`. Validated in `dir=rtl` (ar), both themes.
> **Semantic-color law (D-03/D-04):** green = LONG, red = SHORT, and trade results only. **The score color is NEUTRAL** (brand blue / muted) — green/red MUST NEVER encode the score or be decorative.
> **AI-content law (D-10):** `veteran_note`, `technical_reasons`, `fundamental_reasons`, `news_catalysts`, `invalidation`, `upcoming_risk_events` render **AS-IS** (FR/EN, no re-translation, no rephrasing). Glossary/tooltips are ADDITIVE help only.
> **Producer-boundary law:** front READS only (anon-client + RLS select). Never import the service_role repo in `apps/web`.

## Spacing Scale

Inherited from Phase 2 (Tailwind v4 default 4px scale). Multiples of 4 only.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, chip inline padding, badge gaps |
| sm | 8px | Compact stacks, badge padding, filter chip gap |
| md | 16px | Default element spacing, card inner padding, detail paragraph rhythm |
| lg | 24px | Card padding, gap between signal cards, filter-bar block spacing |
| xl | 32px | Detail section spacing (plan summary ↔ deep analysis), grid row gap |
| 2xl | 48px | Major detail-page section breaks (chart ↔ explanation) on mobile |
| 3xl | 64px | Page top/bottom padding on desktop |

Exceptions:
- **Touch targets:** every interactive control (filter chip, sort selector, "afficher N nouveaux signaux" badge, card link, tooltip trigger, collapse toggle) ≥ 44px tappable. Padding makes up the target; visual size may be smaller. RTL-aware.
- **Card grid:** 1 column < `md`, 2 columns `md`, 3 columns `lg`+ (D-01). Gap = `lg` (24px). Container `max-w-screen-xl`, `px-4 md:px-6 lg:px-8` (logical `ps/pe`).
- **Chart container:** fixed responsive height (e.g. 360px mobile / 420px desktop); canvas LTR regardless of `dir`.

## Typography

Inherited from Phase 2: exactly 4 sizes, 2 weights (Regular 400 + Semibold 600). Body line-height 1.5; heading 1.2; Arabic +0.1 via `:lang(ar)`.

| Role | Size | Weight | Line Height | Phase-3 usage |
|------|------|--------|-------------|---------------|
| Body | 16px | 400 | 1.5 | veteran_note, deep-analysis prose, empty/error copy, disclaimer banner |
| Label | 14px | 600 | 1.4 | card meta labels (actif, risque, R:R, fraîcheur), filter chips, score qualitative label, glossary terms |
| Heading | 24px | 600 | 1.25 | detail page title (asset + direction), section titles ("Explication simple", "Analyse approfondie") |
| Display | 40/56px | 600 | 1.15 | reserved — NOT used on signals surface (no hero here) |

Notes:
- **Score number** rendered prominently within the **Heading** size on the card (e.g. `82` at 24px/600) + qualitative **Label** ("Forte conviction"); both in NEUTRAL color. Tabular figures.
- All prices, scores, R:R, percentages, relative-time wrapped in `<bdi>` + `Intl.NumberFormat`/`Intl.RelativeTimeFormat` (per-asset decimals via Claude's discretion). Do NOT introduce a 5th size or 3rd weight for emphasis — use color/weight tokens already declared.

## Color

Inherits the institutional-blue 60/30/10 brand split from Phase 2 (live tokens in `globals.css`). Phase 3 **introduces the trading-semantic pair** (first appearance in the product) under strict reservation.

| Role | Value (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `#FFFFFF` / `#0B1220` | Page background, list surface |
| Secondary (30%) | `#F4F6F9` / `#141C2B` | Signal cards, filter bar, detail panels, chart container chrome |
| Accent (10%) — brand blue | `#1E5FBF` / `#3B82F6` | Primary CTA, active filter chip, focus ring, **the score emphasis/progress fill** (neutral-brand, NOT green/red), selected sort |
| Long (trading semantic) | green — light `#15803D` / dark `#22C55E` | Direction = LONG only: card direction badge, chart entry/TP context, detail plan. Never decorative, never score. |
| Short (trading semantic) | red — light `#B91C1C` / dark `#EF4444` | Direction = SHORT only: card direction badge, chart, detail plan. Never decorative, never score. |
| Destructive | not used | No destructive actions this phase |

Supporting tokens (not in the 10% accent budget): Text primary `#0B1220`/`#E6EBF2`; Text muted `#5B6675`/`#9AA7B8`; Border `#E2E7EE`/`#26303F`.

**Score color = NEUTRAL (hard rule, D-03):** the score number, its qualitative label, and any score-breakdown bars use brand blue (`--primary`) and/or muted neutrals. Green/red are FORBIDDEN on the score in any form. Score-breakdown bars (recharts, D-11) use a neutral monochrome ramp (tints of `--primary` or muted), one tone per dimension — never a red→green gradient.

**Chart semantic colors (lightweight-charts, D-12):** candle up/down use the same green/short red pair. Entry line = neutral/brand-blue dashed; SL line = red (loss boundary); TP line(s) = green (target). Lines legended with text labels (color is reinforcement, not the only signal — colorblind-safe via labels).

**Accent reserved for (explicit, never "all interactive elements"):**
1. Primary/active filter chip (selected state) and active sort option.
2. Keyboard focus ring (`:focus-visible`) on every interactive element.
3. Score emphasis (number weight + neutral-blue progress/fill) and breakdown bars.
4. The "N nouveaux signaux — afficher" realtime badge (subtle, brand-blue, D-13).
5. Card hover/elevation focus border.

Everything else (rest links, card borders, meta labels, risk text) uses neutral text/border tokens. Green/red appear **only** to encode trade direction and trade-plan price boundaries — nowhere else. Contrast: all pairs meet WCAG AA (4.5:1 body, 3:1 large/UI) in both themes; green/red verified AA against both surfaces.

## Component Anatomy (Claude's-discretion structure, fixed here for the executor)

**SignalCard (D-01, MEMB-01)** — surface `--card`, padding `lg`, radius `--radius-lg`:
- Top row: **asset symbol** (Label/600) · **direction badge** (long=green / short=red, text "Long"/"Short", logical `me`).
- Score block: **NEUTRAL** number (Heading/24) + qualitative label (Label/14, e.g. "Forte conviction") + optional thin neutral progress bar.
- Meta row(s): **risk level** (text + neutral chip), **R:R** (`<bdi>` e.g. "R:R 1:2.4"), **style** (day/swing chip).
- Freshness (D-04): relative age "il y a 2 h" (`Intl.RelativeTimeFormat`, `<bdi>`) + `valid_until` ("valable jusqu'à …" or light countdown).
- Whole card is a link → `/[locale]/(member)/signaux/[id]` (D-17). Hover = subtle border/elevation, no neon.

**FilterBar (D-05/D-06/D-07/D-08)** — surface `--card`/sticky optional:
- Toggle **chips** for `style` (day/swing) and `risk level` (few options, tactile, RTL-friendly).
- **Select/combobox** for `asset` and `asset class` (many instruments) — shadcn `select` or `command`.
- Sort selector: **score desc (default)** · "plus récents" · "meilleur R:R".
- Filters cumulative (AND); state in URL query params (RSC-readable); a "réinitialiser" clear-all when any filter active.

**SignalList (D-13/D-14/D-16/D-18/D-19)** — server-rendered initial load + client realtime overlay:
- Realtime badge (D-13): "N nouveaux signaux — afficher", top, non-intrusive, click inserts.
- Live removal on status transition active→expired/invalidated (D-14), no reflow during reading.
- Cap ~100 (D-19), no pagination. Skeleton grid on load; explicit empty state; error + retry (D-18).

**SignalDetail (D-09/D-11/D-12/D-17)** — RSC route `[id]`, snapshot at load (D-15):
- Title: asset + direction (semantic color) + score (neutral).
- **CandleChart** (client-only, lightweight-charts v5): read-only (no zoom/pan/crosshair), analysis timeframe, ~100–150 candles, entry/SL/TP lines plotted + legended (D-12).
- **Level 1 "Explication simple"**: `veteran_note` AS-IS + plan summary (direction, entry/SL/TP, R:R, risk).
- **Level 2 "Analyse approfondie"** (collapsible/accordion, collapsed by default): `technical_reasons` / `fundamental_reasons` / `news_catalysts` AS-IS + **score breakdown** (recharts bars if components persisted, D-11; else "Facteurs contributifs" list fallback) + `invalidation` scenario + `upcoming_risk_events`.

**Glossary mechanic (D-10, discretion → fixed):** shadcn `tooltip` on a small "?" affix next to recognized jargon terms (RSI/MACD/BOS/ATR…), giving a short vulgarized definition. Additive only — never alters the AI text. Terms + definitions live in a `glossary` message namespace (fr/en/ar). Tooltip trigger ≥ 44px tappable, keyboard-focusable, dismiss on Esc/blur; on touch, tap-to-open.

## Interaction & States Contract

| Surface | States required |
|---------|------|
| SignalCard | rest · hover (subtle border/elevation, no neon) · `:focus-visible` (accent ring, 2px offset) · keyboard-activatable link · RTL mirrored layout |
| Filter chip | rest (neutral) · selected (accent) · hover · focus-visible · ≥44px tap target |
| Asset/class select | closed · open (Radix popover) · selected · focus-visible · searchable; RTL-aware alignment |
| Sort selector | reflects active sort; URL-synced; focus-visible |
| SignalList | loading (skeleton grid) · loaded · empty (reassuring copy) · error (+ retry) · realtime-insert (badge → click reveals, no reflow) · realtime-remove (item disappears on status change) · realtime-lost (silent refetch fallback) |
| CandleChart | loading (skeleton) · loaded (read-only, lines + legend) · render-fail (text fallback: plan summary remains readable without chart) — no zoom/pan/crosshair (D-12); LTR canvas in RTL pages |
| Deep-analysis fold | collapsed (default) · expanded · focus-visible toggle · keyboard operable · animated height (respect `prefers-reduced-motion`) |
| Glossary tooltip | trigger rest/hover/focus · open (mouse hover, keyboard focus, touch tap) · dismiss (Esc/blur/tap-away) |
| Disclaimer banner | always visible on list + detail; not dismissible (legal) |

Responsive: mobile-first; 1→2→3 column grid; filter bar collapses to a compact row/sheet on mobile (discretion). All breakpoints validated in ar/RTL, both themes. `prefers-reduced-motion` honored for realtime insert + fold animation.

Accessibility: chart has a textual plan summary equivalent (D-09 plan summary doubles as the screen-reader description, partial a11y per deferred note); direction/score conveyed by text + color (never color alone); AA contrast both themes.
