<objective>
Build the Signaux view (ADMIN-04, part 1): a read-only, chronological admin list of published signals with Telegram publication status, instrument + status filters, and a dedicated admin read-only detail page that can show any setup regardless of status.

All FR copy (`admin.signals.*`) was already added in Plan 01 — this plan does NOT touch fr.json.
Output: `(admin)/signaux/page.tsx`, `(admin)/signaux/[id]/page.tsx`.
</objective>
