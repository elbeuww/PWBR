# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **SCOPE GUARD (décision D-11 verrouillée) :** Phase 1 est INFRASTRUCTURELLE. Elle pose Tailwind v4 + une primitive RTL minimale UNIQUEMENT. Le design system de marque complet (palette, tokens étoffés, typographie de marque, bibliothèque shadcn) est **explicitement reporté en Phase 2 (vitrine)**. Ce contrat se limite aux 4 contrats transverses réutilisés par toutes les phases suivantes : (1) shell de layout `[locale]`, (2) primitive RTL, (3) sélecteur de langue, (4) états de gating/redirection. Tout token ci-dessous est le MINIMUM nécessaire au RTL et au shell — pas un design system de marque.

## Design System

| Property | Value |
|----------|-------|
| Tool | **none en P1** (shadcn/ui verrouillé pour le projet mais initialisation **différée Phase 2** — D-11) |
| Preset | not applicable (P1) — shadcn préset à définir en P2 |
| Component library | **none en P1** (radix via shadcn arrive en P2). P1 = HTML sémantique + Tailwind v4 logical utilities uniquement |
| Icon library | **lucide-react** réservé/aligné shadcn — en P1 limité au strict minimum : chevron du dropdown langue + glyphe globe. Plein catalogue déféré P2. |
| Font (UI Latin fr/en) | `system-ui` stack (`system-ui, -apple-system, Segoe UI, Roboto, sans-serif`) — police de marque déférée P2 |
| Font (UI Arabe `:lang(ar)`) | `--font-arabic: "Noto Sans Arabic", system-ui, sans-serif` — **obligatoire** : l'arabe exige un support de script dédié, pas seulement Latin (a11y multi-script) |

**Pourquoi pas de shadcn en P1 :** D-11 verrouille « Tailwind v4 + primitive RTL minimale uniquement ». Forcer l'init shadcn maintenant introduirait un design system de marque (thème, tokens, composants riches) = violation de périmètre. Le shell, le dropdown langue et les états de gating de P1 se construisent en HTML sémantique + utilities logiques Tailwind v4. La gate shadcn officielle est donc **différée P2**, pas refusée.

**Stack technique i18n/RTL confirmée (RESEARCH.md / STACK.md) :** next-intl 4.13, Tailwind v4.3 (RTL natif par propriétés logiques — **PAS** `tailwindcss-rtl`, **PAS** `tailwindcss-logical`), Next.js 15 App Router/RSC.

## Spacing Scale

Échelle 8-point (multiples de 4). Posée ici une fois comme contrat transverse réutilisé par toutes les phases. En P1 seules `sm`/`md`/`lg` sont effectivement utilisées (shell + dropdown + pages de redirection).

| Token | Value | Usage P1 |
|-------|-------|----------|
| xs | 4px | Gap icône↔texte dans le bouton de langue |
| sm | 8px | Padding interne des items du dropdown ; gap header |
| md | 16px | Padding horizontal du header ; espacement par défaut |
| lg | 24px | Padding vertical des pages de redirection (tarifs/login placeholder) |
| xl | 32px | Réservé (sections vitrine) — non utilisé en P1 |
| 2xl | 48px | Réservé — non utilisé en P1 |
| 3xl | 64px | Réservé — non utilisé en P1 |

**Direction-awareness (CRITIQUE) :** tout l'espacement directionnel utilise des **propriétés logiques** Tailwind v4 — `ms-*`/`me-*` (margin), `ps-*`/`pe-*` (padding), `start-*`/`end-*` (inset), `text-start`/`text-end`. **INTERDIT** dans tout nouveau code : `ml-*`/`mr-*`/`pl-*`/`pr-*`/`left-*`/`right-*`/`text-left`/`text-right` (ne s'inversent pas en RTL — Pitfall #5 RESEARCH).

Exceptions : touch target minimum **44px** pour le bouton déclencheur du sélecteur de langue (a11y mobile WCAG 2.5.5). Le padding interne peut rester < 44px tant que la zone cliquable totale atteint 44×44px.

## Typography

Système minimal (3 rôles) suffisant pour le shell + dropdown + pages de redirection, pour les **3 scripts (Latin fr/en + Arabe)**. Typographie de marque étoffée déférée P2.

| Role | Size | Weight | Line Height | Usage P1 |
|------|------|--------|-------------|----------|
| Body | 16px | 400 (regular) | 1.5 | Texte des pages de redirection (tarifs/login placeholder), items du dropdown |
| Label | 14px | 600 (semibold) | 1.4 | Libellé du bouton de langue, nom de langue sélectionnée |
| Heading | 24px | 600 (semibold) | 1.2 | Titre des pages placeholder (« Tarifs », « Connexion ») |

Poids déclarés (exactement 2) : **regular 400** + **semibold 600**.

**Contraintes multi-script (a11y i18n) :**
- `:lang(ar)` applique `--font-arabic` (Noto Sans Arabic) ; les tailles ci-dessus valent pour les 3 scripts (l'arabe rend correctement à 16px/1.5 ; ne pas réduire sous 16px en arabe — lisibilité du script).
- **`line-height: 1.5` minimum en arabe** : les diacritiques arabes nécessitent un interlignage généreux ; ne jamais descendre sous 1.5 pour le body en `:lang(ar)`.
- Le **raisonnement IA généré (FR/EN) s'affiche tel quel même en UI arabe** (D-03) : ces blocs restent en police Latin et **`dir="ltr"` local** via `<bdi dir="ltr">` ou un wrapper `dir="ltr"`, pour ne pas casser le flux RTL environnant. (Concerne surtout P3+, mais le contrat est posé ici.)

## Color

P1 = **neutres système uniquement**. Aucune couleur de marque, aucun accent décoratif (palette de marque = D-11 → P2). Le seul rôle « accent » de P1 est l'état de focus/sélection du sélecteur de langue, qui doit rester accessible.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (surface) / `#0A0A0A` (texte) | Fond de page + corps de texte (neutres, contraste AAA ~19:1) |
| Secondary (30%) | `#F4F4F5` (zinc-100) | Fond du header, fond ouvert du dropdown, hover des items |
| Accent (10%) | `#2563EB` (blue-600) | **Anneau de focus clavier UNIQUEMENT** (sélecteur de langue, liens) + indicateur d'item de langue sélectionné |
| Destructive | not applicable (P1) | Aucune action destructive en P1 |

**Accent reserved for :** anneau de focus clavier (`focus-visible`) sur le déclencheur et les items du sélecteur de langue ; coche/indicateur de la langue actuellement active dans le dropdown. **Jamais** appliqué à « tous les éléments interactifs ». La couleur de marque réelle est définie en P2 — `#2563EB` est un neutre fonctionnel d'accessibilité, pas une couleur de marque.

**Contraste :** texte body `#0A0A0A` sur `#FFFFFF` ≥ 7:1 (AAA). Anneau de focus `#2563EB` sur surfaces claires ≥ 3:1 (WCAG 1.4.11 non-text contrast). À revalider quand la palette de marque P2 remplace ces neutres.

## Component Inventory (P1 transverse)

> Les 4 contrats transverses de la phase. Chacun doit fonctionner en LTR (fr/en) ET RTL (ar).

**Points focaux (ancres visuelles).** P1 étant infrastructurel, les ancres sont volontairement minimales :
- **Header :** le **sélecteur de langue** (seul élément interactif) est l'unique point focal, ancré à l'`end` logique.
- **Pages placeholder (tarifs/login/404) :** le **titre Heading 24px/600** est l'unique ancre visuelle ; aucun point focal produit (CTA/marketing) en P1 (déféré P2).

### 1. Shell de layout `[locale]`
- **Structure :** `<html lang={locale} dir={locale==='ar'?'rtl':'ltr'}>` (un seul `<html>`/`<body>`, dans `[locale]/layout.tsx` — jamais dupliqué avec le root layout, Pitfall #7 RESEARCH).
- **Header minimal :** barre horizontale, hauteur 56px, padding inline `md` (16px), fond `secondary`. Contient à l'`end` (logique) le **sélecteur de langue**. Pas de nav de marque en P1 (P2).
- **Slot de contenu :** `{children}` sous le header, padding `lg`.
- **RTL :** le header s'inverse automatiquement (sélecteur passe à gauche en arabe) via positionnement logique `end`. Aucun code conditionnel `dir==='ar'`.

### 2. Primitive RTL — tableau de mapping directionnel
Contrat de substitution physique→logique imposé à tout nouveau code (executor + checker valident par grep) :

| Intention | INTERDIT (physique) | OBLIGATOIRE (logique Tailwind v4) |
|-----------|---------------------|-----------------------------------|
| Marge gauche/droite | `ml-*` / `mr-*` | `ms-*` / `me-*` |
| Padding gauche/droite | `pl-*` / `pr-*` | `ps-*` / `pe-*` |
| Position absolue gauche/droite | `left-*` / `right-*` | `start-*` / `end-*` |
| Alignement texte | `text-left` / `text-right` | `text-start` / `text-end` |
| Arrondi de coin directionnel | `rounded-l-*` / `rounded-r-*` | `rounded-s-*` / `rounded-e-*` |
| Bordure directionnelle | `border-l-*` / `border-r-*` | `border-s-*` / `border-e-*` |
| Icône directionnelle (chevron, flèche) | rendu fixe | miroir via variant `rtl:-scale-x-100` (voir ci-dessous) |

**Éléments intrinsèquement LTR (cœur métier trading — prix/nombres/dates/symboles) :** TOUJOURS isolés en LTR même en flux arabe, via `<bdi>` + `Intl` (next-intl `useFormatter`/`getFormatter`).
- Prix/montant : `<bdi>{format.number(v,{style:'currency',currency:'USD'})}</bdi>`
- Nombre/ratio R:R/score : `<bdi>{format.number(v)}</bdi>`
- Date : `<bdi>{format.dateTime(d,{dateStyle:'medium'})}</bdi>`
- (Contrat posé en P1, consommé massivement en P3/P4/P5. En P1 lui-même : aucune donnée numérique affichée, mais le helper `<Bidi>`/pattern est livré et testé.)

### 3. Sélecteur de langue (dropdown header — D-10)
- **Déclencheur :** bouton, touch target ≥ 44×44px, affiche glyphe globe (`lucide globe`) + nom de la langue active (Label 14px/600) + chevron (`lucide chevron-down`).
- **3 langues :** Français / English / العربية (chaque langue affichée **dans sa propre langue**, autonyme — pas « Arabe » mais « العربية »).
- **Menu :** liste de 3 items, fond `secondary`, padding item `sm`, item actif marqué par coche/indicateur `accent`.
- **Comportement :** au choix → reste sur la **même page** (route inchangée, locale changée — `usePathname`/`useRouter` de `i18n/navigation`), persistance via **cookie next-intl `NEXT_LOCALE`** (D-10).
- **États requis :** `closed` (défaut), `open`, `hover` item (fond hover `secondary` plus foncé), `focus-visible` (anneau `accent` 2px), `selected` (item de la locale active, coche `accent`).
- **Clavier / a11y (WCAG) :** `aria-haspopup="listbox"` (ou menu), `aria-expanded`, navigation flèches haut/bas, `Enter`/`Espace` pour sélectionner, `Échap` pour fermer + refocus déclencheur, `aria-current`/`aria-selected` sur l'item actif. Focus trap dans le menu ouvert. Annonce du nom de langue en toutes lettres (pas juste « fr »).
- **Rendu RTL :** en arabe, le menu s'ancre à l'`end` logique (à gauche), le chevron est **mis en miroir** (`rtl:-scale-x-100` ou variant `rtl:rotate-*` — un chevron pointe vers le bas, donc le miroir concerne surtout les flèches latérales ; pour le chevron-down, le miroir est neutre mais l'ancrage du menu doit suivre `dir`). Le texte des items aligné `text-start`.

### 4. États de gating / redirection (ACCESS-01..04 — couche UX)
> P1 définit les **contrats d'état minimaux** (loading / redirect), PAS le visuel marketing des pages cibles (vitrine = P2).

| Cas (décision) | Comportement observé par l'utilisateur | Surface P1 |
|----------------|----------------------------------------|------------|
| Non-authentifié → surface protégée (D-08) | Redirection vers `/[locale]/login?returnTo=<path>` ; après login, retour à la page demandée | Page **login** (squelette fonctionnel à finaliser si besoin — RESEARCH Q3) |
| Authentifié SANS abonnement actif → `/[locale]/membre…` (D-07) | Redirection vers `/[locale]/tarifs` (levier de conversion, **pas** login) | Page **tarifs placeholder** (titre Heading « Tarifs » + body « Le détail des offres arrive bientôt. » — contenu réel P2) |
| Non-superadmin → `(admin)` (D-09) | **404** (discrétion — ne révèle pas l'existence de l'admin), **pas 403** | `notFound()` natif Next |
| Transition de gate (RSC) | Redirection serveur **avant rendu** (pas de flash de contenu protégé) ; pas de spinner client requis | — |

**Copy des états placeholder :** voir Copywriting Contract. Toutes les chaînes via next-intl (I18N-03) — **aucune chaîne en dur**, y compris les libellés de redirection.
