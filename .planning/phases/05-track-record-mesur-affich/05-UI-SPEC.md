# Phase 5 — UI Design Contract

> Visual and interaction contract for the **measured track record** display: a public-vitrine `% mesuré` block (unblocks the P2/D-08 hidden slot) and a mirror block inside the paid platform, plus a dedicated methodology page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** TRACK-01 (`outcome-tracker` job) and TRACK-02 (`prediction_outcomes` / `pattern_stats` migration) are backend/data work with NO UI surface. This spec covers ONLY TRACK-03 — the display of the measured figures. The job and schema are out of UI scope.
>
> **Inherits the Phase 2 brand contract AND the Phase 3 trading-semantic rules in full** (`02-UI-SPEC.md`, `03-UI-SPEC.md`, live tokens in `apps/web/src/styles/globals.css`). This spec ADDS only what the track-record surface needs: outcome-result green/red usage, the sample-threshold gating display, the always-visible N + method, and the "échantillon insuffisant" state. Where P2/P3 fixed a value (spacing scale, type scale, brand tokens, fonts, icon lib, score=neutral), it is reused verbatim, not re-decided.
>
> **Anti-scam / transparency law (Core Value + D-14/D-15):** the entire point is « % TOUJOURS mesuré, jamais inventé ». The UI MUST: (a) never render a `%` below the N≥30 threshold (D-09), (b) ALWAYS show N next to every figure (D-12), (c) expose the measurement method via tooltip + a dedicated methodology page (D-14), (d) sit alongside the LEGAL-01 disclaimer — a measured track record is NOT a promise of future performance (D-15).
> **Semantic-color law (D-03/D-04 P3):** green/red are RESERVED for trading semantics and trade RESULTS. A win rate / positive expectancy MAY use green, a negative R/expectancy MAY use red — these are real results, the legitimate use D-04 reserved them for. **The score-band color stays NEUTRAL** (carried from P3). Restraint: figures are stated soberly, not as flashy "winning" marketing.
> **RTL is first-class:** every component uses CSS logical properties (`ms`/`me`/`ps`/`pe`/`start`/`end`), never `left`/`right`. All numbers (%, R, expectancy, N) wrapped in `<bdi>` + `Intl.NumberFormat` (D-context discretion: reuse P1 helpers). Validated in `dir=rtl` (ar), both themes.
> **Producer-boundary law:** the vitrine block is PUBLIC → reads aggregated `pattern_stats` via the **anon client** against a dedicated public-read RLS/view (NOT `trade_setups`, which is gated). Front READS only; never import the service_role repo in `apps/web`.

## Spacing Scale

Inherited from Phase 2/3 verbatim (Tailwind v4 default 4px scale). Multiples of 4 only.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap (tooltip "?" affix, method icon), inline chip padding |
| sm | 8px | Compact stacks, badge padding, gap between a figure and its N label |
| md | 16px | Default element spacing, stat-card inner padding, table cell padding |
| lg | 24px | Card padding, gap between stat cards, gap between aggregate block and category table |
| xl | 32px | Section spacing (track-record block ↔ surrounding vitrine sections / methodology sections) |
| 2xl | 48px | Major section break on mobile (between home sections) |
| 3xl | 64px | Page top/bottom padding desktop, methodology page section rhythm |

Exceptions:
- **Touch targets:** every interactive control (period tab, category-view toggle, tooltip trigger, "Voir la méthodologie" link) ≥ 44px tappable. Padding makes up the target. RTL-aware.
- **Content max-width:** methodology page prose capped at `max-w-prose` (~65ch); vitrine track-record block sits in the home container `max-w-screen-xl`, `px-4 md:px-6 lg:px-8` (logical `ps/pe`).
- **Stat grid:** aggregate metrics (win rate · R moyen · expectancy) laid out 1 column < `md`, 3 columns `md`+; gap = `lg` (24px).

## Typography

Inherited from Phase 2/3: exactly 4 sizes, 2 weights (Regular 400 + Semibold 600). Body line-height 1.5; heading 1.2; Arabic +0.1 via `:lang(ar)`.

| Role | Size | Weight | Line Height | Phase-5 usage |
|------|------|--------|-------------|---------------|
| Body | 16px | 400 | 1.5 | method tooltip body, methodology prose, "échantillon insuffisant" copy, disclaimer, table cell text |
| Label | 14px | 600 | 1.4 | metric labels (« Taux de réussite », « R moyen », « Expectancy »), N label (« sur 142 trades »), period tab labels, category table headers |
| Heading | 24px | 600 | 1.25 | track-record block title, methodology section titles, table-section titles |
| Display | 40/56px | 600 | 1.15 | **the headline figure ONLY** — the aggregate win rate `%` rendered prominently (e.g. `64 %` at Display size). One figure max at Display; secondary metrics (R, expectancy) at Heading or Label per layout. |

Notes:
- **The headline win-rate `%`** is the single Display-size element on the vitrine block (the "hero number" of trust). Per-category figures in the table use **Label/Body**, never Display.
- N (sample size) is ALWAYS adjacent to its figure, at **Label 14px** — visually subordinate but never absent (D-12).
- All %, R, expectancy, N wrapped in `<bdi>` + `Intl.NumberFormat` (tabular figures). Do NOT introduce a 5th size or 3rd weight.

## Color

Inherits the institutional-blue 60/30/10 brand split (P2) and the trading-semantic green/red pair (P3, live tokens in `globals.css`). Phase 5 uses green/red for **measured RESULTS** — the legitimate D-04 use.

| Role | Value (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `#FFFFFF` / `#0B1220` | Page/section background, stat-card surface backdrop |
| Secondary (30%) | `#F4F6F9` / `#141C2B` | Stat cards, category table surface, methodology panels |
| Accent (10%) — brand blue | `#1E5FBF` / `#3B82F6` | « Voir la méthodologie » link, active period tab, focus ring, recharts neutral-brand bars, headline-figure emphasis frame (optional) |
| Win / positive result (trading semantic) | green — light `#15803D` / dark `#22C55E` | A POSITIVE measured result only: win rate value emphasis (optional, restrained), positive R moyen / positive expectancy sign. Never decorative. |
| Loss / negative result (trading semantic) | red — light `#B91C1C` / dark `#EF4444` | A NEGATIVE measured result only: negative R moyen / negative expectancy sign. Never decorative. |
| Destructive | not used | No destructive actions this phase (read-only display) |

Supporting tokens (not in the 10% accent budget): Text primary `#0B1220`/`#E6EBF2`; Text muted `#5B6675`/`#9AA7B8` (used for N labels, method tooltip, « échantillon insuffisant » copy); Border `#E2E7EE`/`#26303F`.

**Result-color rule (hard, extends D-04):**
- Green/red MAY color the **sign/direction of a measured result** (positive expectancy = green, negative = red; positive vs negative R moyen) — these are real outcomes, the reserved use.
- **Restraint mandate (anti-scam):** prefer NEUTRAL presentation for the headline win-rate `%` (brand blue or text-primary), reserving green strictly as a subtle reinforcement of an explicitly positive expectancy/R sign. Do NOT paint the whole block green to look "winning" — that reads as hype and contradicts the transparency positioning. Color reinforces a sign already stated in text; it is never the only signal (colorblind-safe).
- **Score bands stay NEUTRAL** (carried from P3): any score-band breakdown of the track record uses brand blue / muted, never red→green.
- **« Échantillon insuffisant » state is NEUTRAL** (muted text), never red — it is not an error, it is honest disclosure.

**Accent reserved for (explicit, never "all interactive elements"):**
1. « Voir la méthodologie » link/button and active period tab (all-time / 90 j).
2. Keyboard focus ring (`:focus-visible`) on every interactive element.
3. recharts comparison bars (neutral-brand monochrome ramp) and optional headline-figure emphasis frame.
4. Active category-view toggle (if a toggle between aggregate and by-category is used).

Everything else (table borders, N labels, method text, disclaimer) uses neutral text/border tokens. Green/red appear **only** to encode a measured positive/negative result sign — nowhere else. Contrast: all pairs meet WCAG AA (4.5:1 body, 3:1 large/UI) in both themes; green/red verified AA against both surfaces.

## Component Anatomy (Claude's-discretion structure, fixed here for the executor)

**TrackRecordBlock (TRACK-03, D-07/D-10/D-11/D-12/D-13/D-14/D-15)** — surface `--card`, padding `lg`, radius `--radius-lg`. Rendered on the vitrine (unblocking the P2/D-08 hidden slot) AND mirrored inside the paid platform from the SAME data source/component:
- Title (Heading/24): « Track record mesuré » (or « Notre track record, mesuré » — see copy).
- **Period tabs** (`tabs`, D-11): « Tout l'historique » (all-time) · « 90 jours ». Both periods available; default = all-time.
- **Aggregate stat row** (D-07/D-10) — the platform-wide figure over all published signals:
  - Win rate `%` — Display size, NEUTRAL by default (the hero number).
  - R moyen — Heading/Label, sign-colored only if explicitly ±.
  - Expectancy (espérance en R/trade) — Heading/Label, sign-colored only if explicitly ±.
  - **N label under/beside each** (Label/14, muted): « mesuré sur N trades clôturés » (D-12). N ALWAYS present.
  - **Method tooltip** (`tooltip`, D-14): "?" affix near the figures → « Mesuré sur N trades réels clôturés. Gagnant = take-profit atteint avant le stop. » + « Voir la méthodologie » link.
- **By-category breakdown** (`table`, D-06/D-13) — SAME dataset simply sliced; PUBLIC on the vitrine (transparency-first):
  - Rows grouped by: par actif / classe d'actif · par style (Day/Swing) · par tranche de score (80–100 / 60–79 / …) · par niveau de risque (Faible/Moyen/Élevé/Extrême).
  - Columns: catégorie · taux de réussite (or « échantillon insuffisant » if N<30) · N. R moyen/expectancy optional per row.
- **Disclaimer adjacency** (D-15): the existing LEGAL-01 `<Disclaimer>` / member banner sits with the block — « Aucune promesse de gain ; un track record mesuré n'est pas une garantie de performance future ».

**Threshold-gated figure (D-09 — HARD RULE):**
- Below **N = 30 completed trades** (global OR per category), render **NO `%`**. Instead show « Échantillon insuffisant — N trades » in NEUTRAL muted text.
- This applies to every figure independently: the aggregate may show a `%` while a thin category still shows « échantillon insuffisant ».
- The threshold display is honest disclosure, not an error or empty state.

**MethodologyPage (D-14)** — dedicated route, prose `max-w-prose`, methodology section rhythm:
- Explains: H1-candle granularity (D-03), the distance tie-break rule (D-04), the « flat » trade valuation at `valid_until` (D-02), the binary TP1-before-SL definition (D-01), definitions of R and expectancy (D-10), the all-time + 90-day periods (D-11), and the N≥30 threshold (D-09).
- Plain, vulgarized language (non-technical MENA audience). FR source; EN/AR translations. No invented numbers — describes method only.

## Interaction & States Contract

| Surface | States required |
|---------|------|
| TrackRecordBlock | loading (skeleton stat row + skeleton table) · loaded-with-figures (N≥30) · loaded-below-threshold (« échantillon insuffisant » per figure) · empty (no completed trades → « en cours de mesure ») · error (+ retry) |
| Period tabs | active (accent) · inactive · hover · focus-visible · ≥44px tap target; switching re-renders figures for the selected period |
| Category table | rows render figure OR « échantillon insuffisant » per row independently (D-09); RTL-aware column order; numbers `<bdi>` |
| Method tooltip | trigger rest/hover/focus · open (hover, keyboard focus, touch tap) · dismiss (Esc/blur/tap-away) · ≥44px trigger |
| « Voir la méthodologie » link | rest (accent) · hover (underline) · focus-visible (accent ring) · RTL-aware |
| Methodology page | static prose; readable; disclaimer present; no data states (descriptive only) |
| Disclaimer | always visible with the block; not dismissible (legal) |

Responsive: mobile-first; aggregate stat row stacks 1→3 columns at `md`; category table scrolls horizontally or reflows to stacked rows on mobile (discretion). All breakpoints validated in ar/RTL, both themes. `prefers-reduced-motion` honored for any recharts/tab transitions.

Accessibility: every figure conveyed by **text + N + label** (never color alone); positive/negative sign stated textually before any green/red reinforcement (colorblind-safe); « échantillon insuffisant » is plain text, not a color state; AA contrast both themes.
