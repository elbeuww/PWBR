## Spacing Scale

8-point scale (Tailwind v4 default, multiples of 4). Cockpit = **dense control room**, so default to the compact end inside tables.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, badge inset, status-light spacing |
| sm | 8px | **Dense table cell padding (py)**, inline action-button gaps |
| md | 16px | Default card padding, axis-section internal spacing |
| lg | 24px | Card-to-card gaps, axis-section breaks on the cockpit home |
| xl | 32px | Cockpit page padding, gap between the 4 axis blocks |
| 2xl | 48px | Top-of-page header → first axis block |
| 3xl | 64px | Reserved (page-level) — rarely used in dense admin |

Exceptions:
- **Dense table rows:** vertical cell padding `8px` (sm), not 16px — supports keyset pages of ~50 rows without scroll fatigue (D-14).
- **Row action touch targets:** icon-only buttons render at `32px` box (sm grid) but keep a `≥40px` hit area via padding for pointer accuracy.

## Typography

Body = Space Grotesk (`--font-sans`). **All numeric/financial values = JetBrains Mono tabular** (`--font-mono`) — non-negotiable for aligned KPI columns and atomic amounts. Exactly 4 roles, 2 weights (400 regular / 600 semibold).

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Data / table cell | 13px | 400 | 1.5 | mono (numbers) / sans (text) | Dense table rows, KPI provenance line (N + période + source) |
| Body / label | 14px | 400 | 1.5 | sans | Default copy, form labels, axis card descriptions |
| KPI value | 20px | 600 | 1.2 | **mono** | Headline metric per axis card (MRR, churn %, funnel counts) |
| Section heading | 28px | 600 | 1.2 | sans (display optional) | Axis section titles ("Revenus", "Ops", …), cockpit page title |

Rules:
- KPI numbers ALWAYS mono + tabular alignment. Atomic amounts via `formatAtomic(BigInt(...))`, never float.
- No size below 13px (WCAG AA readability on dark surfaces, THEME-05).

## Color

60/30/10 split, all values from LOCKED Phase 15 tokens (`globals.css` Layer 2). **Do not introduce new hex/oklch literals** — reference tokens via `var()` / Tailwind semantic utilities only.

| Role | Token / Value | Usage |
|------|---------------|-------|
| Dominant (60%) | `--background` `#070b08` | Page background, dominant surface |
| Secondary (30%) | `--card` / `--secondary` `#0f1611` | Cards, **AdminSidebar**, nav, table containers, axis blocks |
| Accent (10%) | `--primary` `oklch(0.84 0.18 150)` (brand green) | See reserved list below |
| Destructive | `--destructive` `oklch(0.68 0.2 24)` (real red) | Destructive actions only (suspend confirm, error) |

**Accent (`--primary`) reserved EXCLUSIVELY for:**
- The primary CTA in a dialog (e.g. "Offrir le temps", "Confirmer la prolongation").
- Focus ring (`--ring` = brand green) on inputs / interactive elements.
- Active nav item / current axis indicator in the AdminSidebar.
- KPI sparkline/positive trend accent (sober, not glowing).

**Never** apply accent to: every button, table row hover, all links, or status lights. Secondary/destructive buttons stay neutral/`--secondary`.

### Status lights (sémantique feux — D-08 swap law)

Status semantics use the trading namespace tokens, NOT the brand accent (D-05 separation enforced):

| Status | Token | Meaning in cockpit |
|--------|-------|--------------------|
| Healthy / OK / bullish | `--signal-bullish` (green, hue 149) | Ops fresh (`v_data_freshness`), legal review done, active subscription |
| Warning / moderate | `--risk-moderate` (`--nexa-amber-500`) | Data staleness threshold, churn elevated, payout due |
| Critical / failed / bearish | `--destructive` (red, hue 24) | Job failed, data stale red, suspended account, legal review NOT done |

Status colors come from existing helpers — reuse `lib/admin/freshness.ts` (`candleColor`/`ageColor`), `jobs.ts`, `signals.ts`. **Do not hardcode status colors.**

## Copywriting Contract

Admin is **mono-FR**. All copy in French. **VITR-03 / D-13: every KPI is a MEASURED value + N + période + source. Never a fabricated number, never a literal `%` string** (percentages render via `applyThreshold`, source `@app/core`). MRR labelled **« cash encaissé / mois »**, NEVER « MRR récurrent ». Forbidden in admin copy: equity, P&L/PnL, ROI, signed `%` literals (`no-perf-claims` / `no-perf-seed-claims` extended to `(admin)`).

| Element | Copy |
|---------|------|
| Primary CTA — offrir gratuit (D-16) | **« Offrir du temps gratuit »** (row action) → dialog CTA **« Confirmer la prolongation »** |
| Primary CTA — payout (ADASH-05) | **« Marquer comme payé »** → dialog CTA **« Confirmer le paiement »** |
| Cockpit axis drill-down (D-05) | Carte cliquable → **« Voir le détail »** (vers la page détail existante) |
| Empty state heading (table users/file) | **« Aucun résultat »** |
| Empty state body | **« Aucune ligne ne correspond à ces filtres. Ajustez l'état d'abonnement, la source ou la recherche. »** |
| Empty state body (no data at all) | **« Aucune donnée pour cette période. »** |
| Error state (RLS / load fail) | **« Impossible de charger ces données. Vérifiez votre session superadmin puis réessayez. »** |
| KPI provenance line (mandatory, D-13) | **« Mesuré · N = {n} · {période} · source : {source} »** (rendered, never literal numbers in i18n) |
| MRR label (locked) | **« Cash encaissé / mois »** + provenance line. JAMAIS « MRR récurrent ». |

### Destructive / sensitive actions (each = traced gesture, writes `admin_audit_log` atomically)

| Action | Confirmation approach |
|--------|----------------------|
| **Suspendre un compte** (D-17, destructive) | Dialog `AlertDialog`, destructive variant. Title **« Suspendre ce compte ? »** · body **« L'utilisateur sera réellement bloqué (lecture 0 ligne via RLS) jusqu'à réactivation. Action réversible et tracée. »** · requires **reason field** (`p_reason`, required) · confirm CTA **« Suspendre »** (destructive red). |
| **Réactiver un compte** (D-17) | Lighter confirm (non-destructive). CTA **« Réactiver »**. |
| **Offrir du temps gratuit** (D-16) | Dialog with **presets 7 j / 1 mois / 3 mois / custom** (whitelisted intervals). Shows resulting new expiry before confirm. CTA **« Confirmer la prolongation »** (accent). Traced. |
| **Marquer commission payée** (ADASH-05) | Dialog requires `tx_hash` + amount (atomic, read-only display). Anti double-payout enforced DB-side. CTA **« Confirmer le paiement »**. Traced. |

All four actions surface a `sonner` toast on success (Toaster already mounted in layout) and re-disable the row button while pending.

## Interaction States (per surface)

| Surface | Loading | Empty | Error |
|---------|---------|-------|-------|
| Axis KPI card | Skeleton (card height fixed, no layout shift) | "Aucune donnée pour cette période." | Inline error copy + retry, no fabricated zero |
| Dense table (users/file/payouts) | Row skeletons (≤8) | "Aucun résultat" + filter hint | Error banner, table stays mounted |
| Row action (suspend/offrir/payout) | Button disabled + spinner | n/a | `sonner` error toast, row re-enabled |
| Conformité panel | Static (env-driven, instant) | n/a | Show red light if state unreadable |

Pagination control: **« Charger la page suivante »** (keyset cursor), disabled when `hasNext` false. No page numbers (keyset has no offset).
