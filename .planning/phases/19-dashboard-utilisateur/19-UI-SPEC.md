# Phase 19 — UI Design Contract

> Visual and interaction contract for the `(dash)` member shell. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Brownfield phase.** DS v3 (« dark néon unique », green-only) is already shipped (Phases 10/11/15/16). This spec REUSES the locked DS v3 tokens/components — it does NOT invent a new visual language. Every token below is read from `apps/web/src/styles/globals.css` + `apps/web/components.json`. The phase aggregates already-built surfaces (signaux, abonnement, affiliation) into a new shell; the only new member write surface is the watchlist.

## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | shadcn (vendored components, not npm-versioned) | `apps/web/components.json` |
| Preset | `radix-nova` style, baseColor neutral, cssVariables true — DS v3 green-only dark, `forcedTheme="dark"` | components.json + globals.css (P15 D-01/D-04) |
| Component library | Radix primitives (shadcn vendored in `apps/web/src/components/ui/*`) | codebase |
| Icon library | lucide (`iconLibrary: "lucide"`). NOTE: precedent P01 D-01-03-D used inline SVG when `lucide-react` was absent — planner verifies `lucide-react` is installed before importing; fallback = inline SVG. | components.json |
| Fonts | Archivo (`--font-display`, headings/wordmark, utility `font-heading`) · Space Grotesk (`--font-sans`, body/UI) · JetBrains Mono (`--font-mono`, tabular trading figures) · Chakra Petch (`--font-accent`) · Noto Sans Arabic (`--font-arabic`, `:lang(ar)`) | globals.css COUCHE 1 |

**Locked DS v3 rules that bind this phase:**
- `forcedTheme="dark"` — no theme toggle anywhere (settings has language selector only, D-11).
- D-01 (P16): **no néon/glow on navigation chrome** — sidebar + bottom-nav prioritize legibility (Tier App). Glow/accent reserved for value surfaces only.
- D-05 (P10): brand green (`--primary`, hue 150) ≠ trade-signal colors (`--signal-bullish` hue 149 / `--signal-bearish` hue 27). The brand green NEVER encodes a trade direction.
- RTL-safe: logical properties only (`px`/`inset-inline`/`text-start`), `dir` inherited from `<html>` (`[locale]/layout`). No physical left/right.
- VITR-03 / D-09: **NO equity curve, P&L, or ROI chart.** Any `%` rendered via `applyThreshold` + visible `N` + provenance label. Affiliation revenue shown only as measured (`formatAtomic`, BigInt atomic).

## Spacing Scale

Tailwind v4 CSS-first, base unit 4px (`--spacing(n)` = n×4px). Declared standard set `{4, 8, 16, 24, 32, 48, 64}` (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inline padding, card title↔description gap (`gap-1`) |
| sm | 8px | Compact element spacing, chip groups |
| md | 16px | Default card internal spacing (`[--card-spacing:--spacing(4)]`), default element gap |
| lg | 24px | Section padding, gap between overview blocks, page content top padding (`pt-6`) |
| xl | 32px | Layout gaps between major dashboard regions |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level vertical rhythm |

Content max-width: `max-w-screen-xl`, horizontal gutters `px-4 md:px-6 lg:px-8` (matches existing member surface, ExpiryBanner).

Exceptions:
- **12px** — DS v3 compact card token (`Card data-size="sm"`, `[--card-spacing:--spacing(3)]`), already shipped in Phase 10/16. Not a new value — brownfield reuse of an existing DS token, outside the declared standard set.
- **44px** minimum touch target for the watchlist star toggle and every bottom-nav item on mobile (multiple of 4, a11y tap-size). Icon-only controls keep a ≥44px hit area even when the glyph is smaller.

## Typography

Two weights only. Four sizes. Line-heights from existing DS v3 components.

| Role | Size | Weight | Line Height | Notes |
|------|------|--------|-------------|-------|
| Label / meta | 12px (`text-xs`) | 400 regular | 1.5 | Table column meta, badges, provenance tags, `N=…` counts |
| Body / UI | 14px (`text-sm`) | 400 regular | 1.5 (`leading-normal`) | Default UI text — radix-nova default; card description (`text-sm text-muted-foreground`) |
| Heading | 16px (`text-base`) | 500 medium | 1.375 (`leading-snug`) | Card titles (`font-heading text-base leading-snug font-medium`), section labels — Archivo via `font-heading` |
| Display | 24px (`text-2xl`) | 500 medium | 1.2 | Page / overview section title (« cockpit personnel »), Archivo `font-display` |

**Numerals:** all tabular trading figures (prices, score, R:R, follower counts, measured revenue) render in JetBrains Mono (`font-mono`) for column alignment. Arabic (`:lang(ar)`) auto-switches to Noto Sans Arabic at `line-height: 1.6` (globals.css) — heading line-heights above are the LTR baseline; Arabic relaxes them.

## Color

60/30/10 split read from globals.css COUCHE 2 (`:root` / `.dark` resolve identically under `forcedTheme="dark"`).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` `#070b08` (green-tinted near-black) | Page background, dash shell canvas |
| Secondary (30%) | `--card` / `--secondary` / `--muted` `#0f1611`; borders `ring-1 ring-foreground/10` (`--border` rgba(255,255,255,.1)); `--background-alt` `#0b110d` | Cards, sidebar, bottom-nav, settings panels, list rows |
| Accent (10%) | `--primary` `oklch(0.84 0.18 150)` brand green | See reserved-for list below |
| Destructive | `--destructive` `oklch(0.68 0.2 24)` real red | Sign-out affordance styling only (see copywriting) |

**Accent (brand green) reserved for — explicit list:**
1. Primary CTA buttons (e.g. « Renouveler l'abonnement », « Enregistrer les préférences »).
2. Active nav item indicator in sidebar / bottom-nav (subtle fill/underline — NO glow, D-01).
3. Focus ring (`--ring` = brand green) on interactive elements.
4. Active (filled) state of the watchlist star toggle.
5. Inline text links.

NOT applied to: nav chrome at large, card surfaces, body text, table rows, or « all interactive elements ».

**Non-accent semantic colors (already in DS, do not redefine):**
- `--signal-bullish` / `--signal-bearish` — trade direction on aggregated SignalCard/list (owned by existing components, not re-themed here).
- `--risk-moderate` (amber) — ScoreRing risk tier (existing).
- `--muted-foreground` `rgba(212,244,224,.64)` — secondary text; `--muted-tertiary` `rgba(212,244,224,.4)` — tertiary/empty-state text.

## Copywriting Contract

Canonical FR below (i18n parity required for AR/EN/FR — next-intl, strict key parity per P01 D-01-02-A). The renewal/expired state is a **renewal** prompt, never a « free account » upsell (D-03).

| Element | Copy (FR canonical) |
|---------|------|
| Primary CTA (overview, expired) | « Renouveler l'abonnement » → parcours paiement `/tarifs` (reuse ExpiryBanner CTA pattern) |
| Primary CTA (settings) | « Enregistrer les préférences » (langue / notifications) |
| Watchlist toggle | Icône étoile (lucide `Star`), pas de libellé. `aria-label` : « Ajouter à ma watchlist » / « Retirer de ma watchlist » (toggle) |
| Empty — Suivis (ouverts) | Titre : « Aucun signal suivi » · Corps : « Ajoutez un signal à votre watchlist en touchant l'étoile depuis la liste ou le détail d'un trade. » |
| Empty — Historique (clôturés) | Titre : « Aucun signal clôturé » · Corps : « Vos signaux suivis apparaîtront ici une fois clôturés, avec leur issue. » |
| Renewal state (abonné expiré) | Titre : « Votre abonnement a expiré » · Corps : « Renouvelez pour réaccéder à vos signaux et à votre watchlist. » + CTA « Renouveler l'abonnement ». (Onglets signaux/watchlist : la RLS renvoie 0 ligne — barrière réelle, jamais le gate UX seul, D-03.) |
| Affiliation summary (si affilié) | Carte résumé : « X abonnés ramenés · Y revenus mesurés » + lien « Voir mon tableau d'affiliation » → `affiliation/dashboard`. Affichée uniquement si `requireRole('affiliate')` (D-10). |
| Error state | Titre : « Impossible de charger vos données » · Corps : « Vérifiez votre connexion et réessayez. » + action « Réessayer ». |
| Destructive confirmation | **Aucune action destructive nécessitant une modale en Phase 19.** Retrait watchlist = toggle optimiste réversible (D-06, pas de confirmation). Déconnexion = action réversible (re-login) → bouton direct « Se déconnecter », sans modale. (Si le planner ajoute une confirmation de déconnexion : titre « Se déconnecter ? », confirmer « Se déconnecter », annuler « Garder la session ».) |

`<Disclaimer />` systématique (PROJECT.md) reste rendu sur les surfaces signaux remontées — ne pas le retirer en agrégeant.

## Surfaces & Interaction Contracts

Prescriptive interaction rules for the executor (the template's 6 dimensions cover visuals; this section locks behavior the planner must wire).

| Surface | Contract |
|---------|----------|
| Shell `(dash)` | Sidebar latérale persistante (desktop) + bottom-nav (mobile), 6 onglets : overview · signaux (suivis/historique) · watchlist · abonnement · affiliation (résumé conditionnel) · paramètres. Active item = accent fill/underline, NO glow (D-01). Monte les composants existants (`SignalList`, `RevenueTabs`, `ExpiryBanner`) — zéro réimplémentation (D-02). |
| Overview | Ordre vertical figé (D-08) : abonnement + `ExpiryBanner` (J-3/J-1) en tête → 3-4 derniers signaux → raccourcis (watchlist, affiliation si affilié, paramètres). « Cockpit » sobre, aucun chiffre de performance fabriqué (D-09). |
| Suivis / Historique | Source unique `user_followed_setups ⋈ trade_setups`, filtré par statut (ouvert = Suivis, clôturé = Historique). Pagination **keyset** curseur `(created_at desc, id desc)` (D-05). États : loading (Skeleton), empty (copy ci-dessus), error (retry). |
| Watchlist toggle | Étoile sur `SignalCard` (liste) ET dans le détail (D-06). Toggle **optimiste** (react-query) : flip immédiat de l'icône, rollback + toast (sonner) si l'écriture échoue. Hit-area ≥44px. |
| Settings | Compte (email affiché, changement mdp via Supabase auth) + Langue (sélecteur AR/EN/FR, PAS de toggle thème) + Notifications (préférences UI seules, aucune delivery — D-12) + lien gestion abonnement + bouton déconnexion (D-11). |
| Affiliation | Carte résumé conditionnelle seulement (D-10), lien vers dashboard affilié dédié. Pas d'onglet plein. |

States required on every data surface: **loading** (Skeleton), **empty** (copy contract), **error** (copy + retry), **renewal** (expired). All RTL-safe.
