# Phase 11 — UI Design Contract

> Visual and interaction contract for the NEXA component library, transversal reskin, and MERA→NEXA rebranding. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase nature: components + reskin + identity — NOT new product capability.** Phase 10 already shipped the token/font/theme foundation (`apps/web/src/styles/globals.css`, `apps/web/src/lib/fonts.ts`). Phase 11 **consumes** that foundation: it builds the NEXA component library on top of it, reskins every route group, and completes the rebrand. **No token re-decision** — the palette switch (green/purple), the 5 fonts, the 3-layer OKLCH architecture, and the no-flash theme are LOCKED by `10-UI-SPEC.md`. This contract references the **component layer** tokens only (`var()` names like `bg-primary`, `text-foreground`, `font-display`) — never raw primitives, never literal HEX/OKLCH.

## Spacing Scale

8-point scale, inherited from Tailwind v4 defaults + Phase 10. Phase 11 introduces **no** custom spacing tokens.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level / hero spacing |

**Exceptions:** interactive touch targets (icon-only buttons, theme/lang toggles, ScoreRing in list) MUST be **≥44px** hit area even when the visual is smaller (a11y). This is the only sanctioned deviation.

**RTL note (DESIGN-04, hard rule):** ALL spacing/position via **logical properties only** (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, `text-start`, `text-end`). NEVER `ml-/mr-/pl-/pr-/left-/right-/text-left/text-right`. Enforced by `rtl-logical-props.test.ts` (Phase 10). Every new component and every reskinned surface obeys this.

## Typography

Consumed from Phase 10. 4 roles, 2 weights only (regular 400 + semibold 600).

| Role | Size | Weight | Line Height | Family (CSS var) |
|------|------|--------|-------------|------------------|
| Body | 16px | 400 | 1.5 | Space Grotesk (`--font-sans`) |
| Label | 14px | 600 | 1.4 | Space Grotesk; Chakra Petch (`--font-accent`) for eyebrows/cyber labels |
| Heading | 20px | 600 | 1.2 | Archivo (`--font-display`) |
| Display | 28px | 600 | 1.2 | Archivo (`--font-display`) |

**Numeric / tabular data** (score, price, SL/TP, R:R, N, win-rate): always `--font-mono` (JetBrains Mono), tabular figures. Prices/numbers wrapped in `<bdi>` to resist RTL inversion (established pattern, D-02-03-A).

**Arabic:** `:lang(ar)` keeps `line-height: 1.6` (diacritics). RTL from `<html dir="rtl">` + logical props, not the font.

## Color

NEXA palette is **already live** (Phase 10). Phase 11 only references the **component/semantic layer**. Values below are the locked Phase 10 contract — repeated here for the checker, NOT re-decided.

| Role | Light | Dark | Usage |
|------|-------|------|-------|
| Dominant (60%) | `oklch(1 0 0)` white | `oklch(0.1663 0.0262 269.37)` ink navy | `--background`, page surfaces |
| Secondary (30%) | neutral light card | dark slate navy | `--card`, `--secondary`, `--muted`, header/footer/nav |
| Accent (10%) | cyber green `oklch(0.7754 0.1896 155.45)` (`#03d87f`) | brightened green | `--primary`, `--ring` |
| Secondary brand | royal purple `oklch(0.4233 0.1772 302.98)` (`#63279b`) | dark-tuned | eyebrows, gradients, mark gradient |
| Destructive | `oklch(0.5771 0.2152 27.33)` (`#dc2626`) | dark-tuned | destructive UI actions ONLY (delete/cancel) |

**Accent (brand green) reserved for (explicit — never "all interactive elements"):**
- Primary CTA buttons (`--primary`)
- Focus rings (`--ring`)
- Active nav / selected-state indicators
- Brand wordmark / mark gradient + eyebrow accents (royal purple variant)

Links, secondary buttons, borders → neutral/secondary tokens, never brand accent.

### Trading-signal tokens — SEPARATE namespace (D-05, hard rule)

Brand cyber green (`oklch(0.7754…)`, hue 155, vivid) **must never** encode trade direction. Distinct tokens:

| Signal token | OKLCH | Use |
|--------------|-------|-----|
| `--signal-bullish` | `oklch(0.6271 0.1699 149.21)` (`#16a34a`, sober) | win / long |
| `--signal-bearish` | `oklch(0.5771 0.2152 27.33)` (`#dc2626`) | loss / short |

**ScoreRing risk color (D-12):** maps to a neutral→amber→bearish scale — it borrows `--signal-bearish` only at the "élevé" extreme. It NEVER uses `--primary` or `--signal-bullish`. Risk ≠ direction ≠ brand.

### CandleChart recoloring (UI-03, Anti-Pattern 5)

`apps/web/src/components/signals/CandleChart.tsx` currently hardcodes old v2.0 brand-blue colors (`UP #15803D`, `DOWN #B91C1C`, `ENTRY #1E5FBF`, `SL #B91C1C`, `TP #15803D`). lightweight-charts does NOT read CSS vars. Recolor via the **lwc JS API only** (Claude's-discretion mapping: `getComputedStyle` on a token-bearing node, OR a tokens→hex mapping table passed to `addSeries`). Target: `UP/TP → --signal-bullish`, `DOWN/SL → --signal-bearish`, `ENTRY → neutral foreground`. **Recolor only** — never migrate the RLS fetch to the client (Anti-Pattern 3).
