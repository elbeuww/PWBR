## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visiteur → middleware (?ref) | input non fiable dans l'URL, validé regex avant pose du cookie |
| client → cookie aff_ref | cookie httpOnly non lisible/forgeable depuis JS |
| signUp → DB (referrals) | écriture via service_role (RLS interdit le front) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-REFINJ | Tampering/Injection | captureRef | mitigate | regex `^[A-Z0-9]{3,20}$` AVANT pose du cookie ; jamais concaténé |
| T-07-COOKIE | Tampering | cookie aff_ref | mitigate | httpOnly + secure + sameSite=lax ; code forgé → no-op à la résolution DB (attributeReferral) |
| T-07-ATTR-CRASH | Denial of Service | signUp | mitigate | attribution best-effort en try/catch ; un code invalide ne bloque jamais l'inscription (A2) |
| T-07-SELFREF | Tampering/Fraud | attributeReferral | mitigate | skip self-ref au repo + exclusion au calcul (D-12) |
| T-07-RLS-WRITE | Elevation | écriture referrals | mitigate | service_role local (admin-service server-only) ; aucune policy write front |
