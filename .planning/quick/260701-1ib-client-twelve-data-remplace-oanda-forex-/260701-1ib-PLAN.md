- Endpoint : `GET https://api.twelvedata.com/time_series?symbol=EUR/USD&interval=1h&outputsize=5000&start_date=...&end_date=...&timezone=UTC&apikey=...`
- FREE couvre : EUR/USD, GBP/USD, AUD/USD, USD/JPY, XAU/USD. PAS XAG/USD ni WTI (→ 404 "Grow or Venture plan").

  `datetime` daily (1day) = "2026-07-01" (date seule) ; intraday = "2026-07-01 10:00:00" (espace, pas ISO).
  `volume` forex souvent "0" ou absent.
- Erreur : `{ "status":"error","code":404|429,"message":"..." }` — HTTP peut rester 200 avec status=error → gérer les DEUX (HTTP !ok ET body status=error).
- Mapping : source_symbol DB "EUR_USD" → "EUR/USD" (remplacer "_" par "/"). Granularité interne H1→1h, H4→4h, D→1day.
- TWELVEDATA_API_KEY présent dans apps/jobs/.env (gitignore).
