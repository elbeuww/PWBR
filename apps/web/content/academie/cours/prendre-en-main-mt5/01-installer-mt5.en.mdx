This first lesson installs MetaTrader 5 and opens a session on a demo account. We stay on demo until the workflow is mastered: no real capital is exposed.

## Installation steps

<Steps>
1. Download the installer from your broker's official site, never from a third-party link.
2. Run the installer and accept the default location.
3. On first launch, choose "Open a demo account".
4. Select your broker's demo server and confirm.
</Steps>

<Callout variant="astuce">
Write down the account number and password shown when the demo account is created: they are displayed only once.
</Callout>

## Verify the connection

At the bottom right of the platform, an active connection shows a data throughput. If the status stays empty, check the selected server before doing anything else.
