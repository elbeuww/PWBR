# NEXA — Brand reference (v2.1)

**Marque :** NEXA — *New Era Exchange Alliance* → FR « Nouvelle Ère · Alliance d'Échange ».
**Baseline conforme :** descripteur factuel, **sans promesse de gain** (le slogan « Make Everybody Rich Again » du mock MERA est écarté).

## Palette de marque

| Rôle | Couleur | Hex |
|------|---------|-----|
| Primaire | Cyber green | `#03d87f` |
| Accent | Royal purple | `#63279b` |

Les tokens du design system (OKLCH, `globals.css`) se construisent autour de ces deux couleurs (cf. DESIGN-01).

## Logo

**Direction retenue : `logo-concepts/C2-emblem.jpg`** — emblème hexagonal avec un « N » lisible.

> ⚠️ Les fichiers de `logo-concepts/` sont des **références conceptuelles** générées via fal.ai (`flux/schnell`, modèle bon marché). Le modèle a dérivé la palette (cyan/magenta au lieu de green/purple). Le **mark de production sera redessiné en SVG propre** aux hex exacts (#03d87f / #63279b), décliné mark + wordmark + favicon + variantes clair/sombre + image OG (cf. BRAND-03), pendant la phase design.
